这里有什么

按赛季浏览 FTC 官方获奖结果、公开工程作品集和队伍公开资料；不随赛季变化的技术站与工具放在独立栏目。

用法：先选择栏目；获奖结果、工程作品集和队伍公开资料会显示赛季导航。队伍资料可按活跃度或队号排序，并按 CAD、代码、视频、网站等类型筛选。

获奖结果

这里有什么

六个赛季的 Impact Award 获奖材料（essay、视频、演示）、公开 CAD / 代码 / Build Thread 的开源队伍、FIRST 官方名人堂，还有常用的工具和学习资源。切换上方赛季键，内容会跟着变。

用法：点赛季键切换年份。「Impact 智库」看该赛季全部获奖材料；「开源队伍」按 Build Thread 访问量排序，有 CAD / 代码 / 视频的直接点进去看；「技术资源」按分类找工具。链接可分享，网址后加 #2024 这类锚点能直接定位赛季。
